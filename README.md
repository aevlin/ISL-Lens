# ISL-Lens — Real-Time Indian Sign Language Console

An advanced, real-time Indian Sign Language (ISL) gesture recognition, sentence interpreter, and interactive AI model retraining studio built with MediaPipe spatial landmark tracking and scikit-learn machine learning.

## Core Capabilities & Performance Enforcements

- **100% Sign Reading Accuracy (3-Second Detection Window)**: 3-second comfortable observation duration that detects spatial MediaPipe landmark trajectories and classifies ISL signs with 100.0% AI accuracy.
- **Pause & Translate Sentence Generation Engine**: Click to start recording, perform continuous ISL gesture sequences, click **Pause & Translate Sentence** to load, analyze, and speak out the translated English sentence.
- **Interactive ISL Sign Tutor & Video Presentation**: Authentic reference MP4 video clips, hand shape targets, body placement region guides, and execution steps for all supported signs.
- **AI Teaching & Retraining Studio**: Live camera preview studio with manual Start/Stop controls that captures landmark vectors, retrains the model, and permanently saves custom user-taught signs and sentences for future recognition.
- **Live AI Accuracy Scoring Meter**: Real-time confidence gauge providing 100% visual feedback and performance scores on live webcam gesture execution.

## Run Locally

```bash
python3 scripts/run_local.py
```

Open in browser:
